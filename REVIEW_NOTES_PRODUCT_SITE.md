# Product-led website redesign review

This branch replaces the previous synthetic motion-heavy landing page with a quieter product-led presentation.

- Uses Cloth NeXt logos and icon assets from the repository.
- Removes generated canvas physics scenes, HUD overlays, cursor glow, parallax and tilt effects.
- Keeps motion limited to subtle reveal transitions and the sticky header.
- Structures the page around product capabilities, character collision cages, pinning, recovery, workflow and requirements.
- Updates the visible product story to Cloth NeXt 2.2 Beta.

Visual validation was performed at 1440 × 1000 and 390 × 844. JavaScript syntax, HTML parsing, responsive width and browser console output were checked.
