THE PRODUCT

Powerful solver.
Practical workflow.

PPF does the simulation. Cloth NeXt handles everything an artist needs before, during and after the solve.

SHARED CONTACT

Simulate the scene, not isolated pieces.

Cloth, cables, soft bodies and colliders participate in the same simulation workflow, with self contact and object-to-object interaction.

MATERIALS

Start from fabric.

Choose from 75 categorized presets, then tune artist-facing properties such as stretch, bend and friction.

SOLVER CONTROL

Use the right solver release.

Managed and external solver installations can live side by side with explicit compatibility checks and selection.

CHARACTER COLLISION CAGES
ANIMATED CHARACTERS

Build collision around the rig.

Create conservative, animation-aware collision cages for character workflows. Per-bone proxies reduce the cost of preparing dense animated meshes while keeping the contact setup visible in Blender.

  • Animation-aware proxy generation
  • Per-bone collision structure
  • Reusable evaluated data and cache identities
HARD + SOFT PINS
CONTROL WHERE IT MATTERS

Hold it. Follow it. Let it yield.

Use hard pins for fixed attachment and soft pins for controlled movement. Animated targets stay synchronized with collider sampling across the bake range.

  • Hard and soft constraint modes
  • Static or animated targets
  • Vertex-group driven setup
VERIFIED RECOVERY
LONG BAKES

A crash should not erase a valid checkpoint.

Cloth NeXt preserves authenticated recovery data after an unexpected solver exit and verifies that the checkpoint belongs to the active solver installation before resuming.

  • Authenticated checkpoint identity
  • Solver-release compatibility checks
  • Clear recovery state in Blender
THE WORKFLOW

From Physics Properties
to a verified cache.

  1. 01

    Assign roles

    Set meshes, curves and empties as Cloth, Rod / Cable, Soft Body, Collider or Force.

  2. 02

    Choose a material

    Start from a categorized preset and tune the physical response for the shot.

  3. 03

    Validate the scene

    Catch geometry, storage, compatibility and memory problems before the expensive step.

  4. 04

    Bake with feedback

    Follow preparation, progress, frame fill and system load while the solver runs.

  5. 05

    Review the result

    Return to a versioned playback cache with deterministic invalidation and recovery state.

Cloth NeXt and PPF are separate projects.

Cloth NeXt provides the Blender workflow. The PPF Contact Solver is maintained by ST Tech / ZOZO and is never bundled with the add-on.
