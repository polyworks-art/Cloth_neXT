01
QUICK START

Your first simulation.

The fastest useful test is one Cloth object falling onto one Collider. Keep the scene tiny until the full pipeline works, then scale up.

1

Prepare simple geometry

Start with a subdivided plane or simple garment panel and a second mesh that will act as the collision object. Apply sensible object scale before you start tuning physics.

2

Enable Cloth NeXt on both objects

Open Blender Physics Properties, enable Cloth NeXt and assign the deforming mesh the Cloth role. Set the collision object to Collider.

3

Choose a cache directory

Use Set Dir in the Simulation controls. Keep enough free disk space for the frame range and geometry you plan to simulate.

4

Pick a material preset

Choose a fabric preset that roughly matches the result you want. Treat presets as starting points. Stretch, bend, weight and friction still need shot-specific tuning.

5

Use a short Bake range

Test 20 to 50 frames before committing to a full animation. Short tests make collision, material and scale problems much faster to diagnose.

6

Bake and inspect

Press BAKE. Cloth NeXt validates the scene, hands the solve to the external PPF Contact Solver and attaches the resulting playback cache back in Blender.

Good first result

The cloth falls, collides, settles and plays back without exploding, tunneling or stretching far beyond the intended material response. Once that works, add animation, pins and more complex contact one step at a time.

02
INSTALLATION

Two pieces, one workflow.

Cloth NeXt is the Blender integration. The PPF Contact Solver is separate software maintained by ST Tech / ZOZO and is never bundled inside the extension.

PART 1

Install Cloth NeXt

Install the Cloth NeXt ZIP through Blender's Extension system, then enable the extension. Normal add-on updates also use Blender's native extension workflow.

PART 2

Connect PPF

Use a managed solver installation, select an external installation, or connect to an already-running external server. Cloth NeXt verifies compatibility before simulation.

Managed installation

Cloth NeXt can download an explicitly approved compatible solver release from its official source, verify it and install releases side by side in the Cloth NeXt solver directory.

External installation

Select a solver you already installed. Cloth NeXt may validate and start it, but it does not modify, delete or update files that belong to your external installation.

External server

Connect to an already-running PPF server. Cloth NeXt treats that process as externally owned and does not take over its lifecycle.

Run the Solver Health Check before your first real Bake.

If the health check fails, fix that first. Material tweaking cannot compensate for a solver installation or compatibility problem.

03
MENTAL MODEL

Blender stays the stage. PPF does the solve.

Cloth NeXt does not replace Blender. It prepares evaluated scene data, validates the setup, sends supported simulation data to PPF, receives solved frames and returns them as Blender playback.

1Blender sceneRoles, animation, materials, pins, forces
→
2Cloth NeXtValidation, export, compatibility, orchestration
→
3PPFGPU simulation and contact solve
→
4Playback cacheVerified result returned to Blender
Object roles tell Cloth NeXt what participates.

Every enabled object has a specific job in the solve. The role controls which settings are relevant and how data is exported.

Scene-wide settings must agree.

Objects that participate in the same interacting solve share the simulation range and scene-level quality/contact context.

Validation is part of the workflow.

Topology, compatibility, cache and geometry problems are much cheaper to catch before the solver has spent minutes on a shot.

The final cache is authoritative.

Live View is for feedback while solving. The finalized playback cache is what you should judge and render from.

04
NEW LOOK

The compact viewport workflow.

New Look is the optional floating simulation interface. Enable it in Cloth NeXt preferences when you want the core Bake controls close to the viewport instead of the legacy Simulation block.

Set Dir
Low ▼
BAKE

Set Dir

Chooses the cache location used by the production Bake workflow. The status reflects the actual configured directory rather than a separate UI-only state.

Quality

Switch solver-quality presets from the toolbar. Extreme is intentionally highlighted in red to communicate that it is the expensive end of the preset range.

BAKE

Starts the same canonical Bake workflow as the legacy UI. If the scene is not ready to simulate, the button remains unavailable instead of bypassing validation.

F6 show and hide

F6 temporarily slides the toolbar below the viewport edge and brings it back. The shortcut can be changed through Blender's native keymap UI. Hiding the toolbar does not switch New Look off.

New Look changes presentation, not simulation logic.

Cache state, Bake eligibility, progress, diagnostics, quality and recovery still come from the same underlying Cloth NeXt systems.

05
SIMULATION ROLES

Give every object one clear job.

The role is the first major decision. It determines what gets simulated, what stays authored in Blender and which settings are shown.

Cloth

Surface fabric

Use for garments, flags, sheets and other triangle-shell fabric surfaces. Cloth supports material presets, collision, pressure, shrink, sewing and vertex-group pinning.

Collider

Collision geometry

Use for bodies, props, floors and other obstacles. Colliders can remain static or capture supported Blender animation and topology-preserving deformation.

Rod / Cable

One-dimensional centerlines

Use supported Curve splines for ropes, cables and similar linear elements. The solver acts on the centerline while Blender bevel and visual radius remain presentation.

Soft Body

Volumetric deformation

Use a closed manifold mesh when you need volume deformation rather than a thin shell. Cloth NeXt requests internal tetrahedralization for the solve.

Rigid Body

Solver-driven rigid motion

Use for solid objects that should participate in the shared solve but preserve rigid shape. Contact and mass-related settings remain relevant while elastic deformation does not.

Force

Scene forces

Use Blender Empties for supported scene forces such as gravity and wind. Orientation gives the force direction and multiple forces can contribute to the same solve.

06
CLOTH MATERIALS

Tune behavior, not mystery numbers.

Cloth NeXt maps artist-facing controls to real PPF parameters. Start with a preset, then change only the behavior you can identify in the result.

37 material presets

The library includes seven Essentials and 30 research-derived starting points based on measurements from the MIT Fabric Properties Dataset. Research presets are grounded starting points, not exact digital certificates for a commercial textile.

Shrink can also expand

+10% means a 90% rest scale. -10% means a 110% rest scale. This changes the cloth rest shape, not the Blender object scale.

Shrink and Stretch Limit conflict

Non-zero Shrink cannot be combined with an enabled non-zero Stretch Limit for the same shell setup. Cloth NeXt reports this before Bake instead of silently changing either setting.

07
PINNING

Attach cloth to the performance.

Pinning uses an ordinary Blender vertex group. Vertices above the supported weight threshold become constrained by the selected pin mode.

STATIC

Hold the starting position

Pinned vertices stay at their evaluated Bake Start positions. Use this for fixed anchors such as a flag edge, curtain rail or static garment attachment.

FOLLOW ANIMATION

Follow Blender motion

Pinned vertices follow evaluated Blender positions across the Bake range. Use this when attachment points need to move with a rig or other supported animation.

BEST PRACTICE

Keep pin groups as small as the design allows. Over-pinning can remove natural secondary motion and can create impossible contact situations if the constrained vertices are driven through collision geometry.

08
COLLIDERS

Build contact the solver can trust.

Collider quality matters as much as cloth quality. Clean, conservative collision geometry usually beats a dense production mesh.

Static

Use when the obstacle does not move or deform during the Bake. It is the cheapest and simplest collision case.

Animated transform

Use for objects moving through Blender transforms, parenting, constraints or other supported evaluated motion without topology changes.

Deforming animation

Use supported topology-preserving deformation such as armatures, shape keys and compatible deforming modifiers. Topology changes are rejected before solving.

Character Collision Cage

Cloth NeXt can create conservative proxy collision around a rig so character motion can be represented with simpler collision geometry. Always inspect the cage through the full motion range before committing to a long Bake.

FORCES

Drive the scene with Blender objects.

Force roles use Blender Empties so direction and animation stay visible in the scene rather than disappearing into an abstract solver dialog.

BEST PRACTICE

Animate one force at a time while tuning. When several animated forces overlap, it becomes much harder to tell which parameter is responsible for unwanted motion.

10
BAKE AND LIVE VIEW

Watch the solve without confusing preview with final data.

Bake is a staged process. Cloth NeXt validates the scene, prepares solver input, runs PPF, streams confirmed frames for Live View, then publishes a finalized playback cache.

  1. 01
    Validate

    Check scene state, supported geometry, cache destination, solver compatibility and relevant preconditions.

  2. 02
    Prepare

    Capture the evaluated Blender data needed for the solve, including supported collider and pin animation.

  3. 03
    Simulate

    PPF advances the physical solve and Cloth NeXt receives completed frame data.

  4. 04
    Live View

    Blender advances only to a frame that is completely available. While a cache is still growing, the viewport holds the last confirmed frame instead of interpolating toward unwritten data.

  5. 05
    Finalize

    The completed cache is validated and attached for normal Blender playback.

Use quality intentionally

Start low enough to iterate quickly. Increase quality when the motion and material setup are already correct. Extreme should be a deliberate choice, not the default troubleshooting button.

Cancel when the setup is wrong

If you spot a bad collider, material response or animation issue, cancel early. Fix the source problem and Rebake instead of waiting for a cache you already know you will discard.

11
CACHE AND RECOVERY

Treat playback as versioned simulation output.

Cloth NeXt uses transactional playback caches so an incomplete new Bake does not casually replace a valid previous result.

Rebake when solver-visible inputs change.

Material, geometry, relevant modifiers, collision, pins, forces and simulation settings can invalidate the relationship between the scene and the existing cache.

Keep cache storage stable.

A cache directory is part of the production workflow. Avoid moving or deleting active cache files behind Blender while the result is attached.

Recovery is verified, not guessed.

When resumable solver state is available, Cloth NeXt checks that it belongs to the correct simulation and compatible solver context before offering recovery.

Do not judge a crash from the viewport alone.

Use the visible error code and Diagnostics details. Recovery and cache cleanup depend on the actual failure stage.

12
TROUBLESHOOTING

Fix the first real failure, not the loudest symptom.

Cloth NeXt errors are designed to be actionable. Start with the visible CNX code and the stage that failed, then change one thing at a time.

1

Read the visible message

Errors are shown as errors, not normal status. Record the CNX code if one is provided.

2

Open Diagnostics

Use the existing diagnostics action to see the technical context without guessing from a single viewport symptom.

3

Check scene health

Resolve invalid geometry, unsupported topology changes, missing cache storage and incompatible solver state before retesting.

4

Reduce the scene

Shorten the frame range, isolate one garment or simplify contact until the failure becomes reproducible and understandable.

5

Use the public error reference

Look up the CNX code for the maintained explanation and suggested action.

13
UPDATES

Choose how much change you want.

Cloth NeXt uses Blender's Extension system for add-on updates. The solver has its own separate lifecycle and is never silently replaced by an add-on update.

Stable

Production first

Use for normal work and releases that have passed the Stable release gates.

Beta

Earlier fixes and features

Use when you want release candidates and newer functionality before it reaches Stable.

Dev

Active testing

Use for experimental snapshots when you intentionally want the newest development state and accept additional risk.

For production, default to Stable.

Change channels because you need a specific fix or feature, not simply because a higher version number exists.
