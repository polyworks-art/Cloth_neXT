01 · BEGINNER

Your First Simulation

Use one subdivided plane as Cloth and one simple mesh as Collider. Enable Cloth NeXt on both objects, assign the roles, choose a valid cache directory and keep the first Bake short. A 20 to 50 frame test is enough to verify the complete pipeline before you add animation or extra contact.

  1. Apply sensible object scale and start from clean geometry.
  2. Choose Cloth for the deforming object and Collider for the obstacle.
  3. Set the cache directory with Set Dir.
  4. Choose a material preset close to your target fabric.
  5. Bake a short range and inspect contact, stretch and settling.
If the tiny test fails, fix the setup first. Do not compensate for a broken pipeline by changing random material values.
02 · BEGINNER

Install Cloth NeXt and Connect PPF

Cloth NeXt is the Blender integration layer. The PPF Contact Solver is separate software maintained by ST Tech / ZOZO. Cloth NeXt can work with a managed installation, a solver you installed yourself, or an already-running external server.

ManagedCloth NeXt downloads an explicitly approved compatible release from the official source, verifies it and installs it side by side.
External installationSelect a solver you already own. Cloth NeXt validates it but does not modify or update its files.
External serverConnect to a server that is already running. Cloth NeXt does not take over its process lifecycle.
Run Solver Health Check before the first production Bake.
03 · BEGINNER

Use the New Look Toolbar

New Look is the optional compact viewport interface. Set Dir chooses the production cache location. Quality changes the same solver quality presets used elsewhere. BAKE starts the canonical Bake workflow and stays unavailable when the scene does not meet the real Bake requirements.

CNXSet DirLow ▾BAKE

F6 temporarily slides the toolbar below the Viewport edge. Press F6 again to bring it back. The shortcut is editable through Blender's native keymap system. Extreme quality remains red so it is easy to recognize.

04 · BEGINNER

Tune Cloth Materials

Start from a preset, then change the few properties that describe the problem you actually see. Surface Weight changes inertia. Stretch Resistance controls in-plane stretch. Bend Resistance changes how readily folds form. Friction affects sliding contact. Pressure pushes outward. Shrink changes the rest shape.

ControlUse it when
Surface WeightThe fabric feels too light or too heavy in motion.
Stretch ResistanceThe cloth elongates too easily or feels too rigid in-plane.
Bend ResistanceFolds are too sharp, too soft or too broad.
Surface GripContact slides too freely or sticks too strongly.
ShrinkYou want a smaller or larger rest shape. Positive values contract, negative values expand.
Shrink and an enabled non-zero Stretch Limit cannot be combined. Cloth NeXt reports that conflict before Bake.
05 · INTERMEDIATE

Pin Cloth to Animation

Pinning uses an ordinary Blender vertex group. Static pins hold the evaluated Bake Start positions. Follow Animation samples the evaluated Blender positions across the Bake range and sends those positions to the solver. Keep the pin group focused around attachment regions rather than painting half the garment at full weight.

  1. Create a vertex group on the Cloth object.
  2. Paint only the vertices that should be constrained.
  3. Choose Static for a fixed attachment or Follow Animation for animated targets.
  4. Test the attachment with a short range before running the full shot.
06 · INTERMEDIATE

Animated Colliders and Character Cages

Static Colliders are ideal for fixed obstacles. Animated Colliders capture evaluated Blender transforms and supported topology-preserving deformation. For characters, collision cages reduce the amount of geometry sent into the contact solve while following the animated body.

Topology changes during the Bake range are rejected. Armatures, shape keys and supported deforming modifiers are useful only while the evaluated topology remains stable.
07 · INTERMEDIATE

Gravity, Wind and Air

Force objects use Blender Empties as artist-friendly controls. Gravity points along local negative Z. Wind points along local positive Z. Rotate the Empty to aim the force. Multiple supported force contributions can participate in the same scene and animated values are sampled for the solve.

GravityUse direction and magnitude to define the scene acceleration.
WindUse direction and strength for animated environmental motion.
AirUse Air Density, Air Friction and Vertex Air Damping to shape aerodynamic response.
08 · INTERMEDIATE

Bake and Live View

BAKE first validates the scene, prepares evaluated inputs and starts the external solver. Live View is progress feedback while the result is still being written. Cloth NeXt only exposes confirmed complete PC2 frames and holds the last confirmed frame until the next one is fully available. Finalized playback uses the normal final cache behavior.

Cancel uses the existing solver cancellation path. A cancelled or failed Bake should not destroy the previous valid playback result.
09 · ADVANCED

Caches, Rebake and Recovery

Cloth NeXt treats playback caches as versioned production data. A successful Bake records the geometry and settings identity used to create the result. Changing solver-visible settings or geometry invalidates that relationship and a Rebake is required.

  1. The old valid result remains authoritative while a replacement Bake starts.
  2. The new cache is verified before Cloth NeXt hands playback over to it.
  3. Obsolete owned cache generations are cleaned only after the successor is committed.
  4. Recovery data is accepted only when it matches the expected solver and scene identity.
10 · ADVANCED

Troubleshoot a Failed Bake

Start with the first clear CNX error instead of changing several settings at once. Separate installation failures, geometry failures, contact failures, storage failures and cache failures. The Errors page gives stable guidance for public CNX error codes.

1Read the first error

Use the exact CNX code and message.

2Check solver health

If the solver cannot pass its health check, stop there.

3Reduce the scene

Use a short range and remove unrelated objects until the failure is isolated.

4Use Diagnostics

Export a privacy-safe report when you need support.

11 · INTERMEDIATE

Choose the Right Simulation Role

ClothTriangle shell deformation and garment simulation.
Rod / CableOne-dimensional curve simulation for cables and ropes.
Soft BodyVolumetric deformation from a closed manifold mesh.
Rigid BodySolid moving body behavior for supported scenes.
ColliderStatic or animated collision geometry.
ForceScene gravity, wind and aerodynamic controls.
12 · ADVANCED

Stable, Beta and Dev Channels

Stable is the production promise. Beta is for release candidates and newer fixes that still need broader validation. Dev is for active testing and may contain experimental work. Cloth NeXt uses Blender's Extension system for add-on updates rather than replacing its own files while running.

StableUse this for normal production work.
BetaUse this when you intentionally want to test upcoming releases.
DevUse this only when you understand that the build may be experimental.
