Stable, Beta and Dev Channels

Stable is the production promise. Beta is for release candidates and newer fixes that still need broader validation. Dev is for active testing and may contain experimental work. Cloth NeXt uses Blender's Extension system for add-on updates rather than replacing its own files while running.

StableUse this for normal production work.
BetaUse this when you intentionally want to test upcoming releases.
DevUse this only when you understand that the build may be experimental.
