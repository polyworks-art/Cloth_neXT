Use the New Look Toolbar

New Look is the optional compact viewport interface. Set Dir chooses the production cache location. Quality changes the same solver quality presets used elsewhere. BAKE starts the canonical Bake workflow and stays unavailable when the scene does not meet the real Bake requirements.

CNXSet DirLow ▾BAKE

F6 temporarily slides the toolbar below the Viewport edge. Press F6 again to bring it back. The shortcut is editable through Blender's native keymap system. Extreme quality remains red so it is easy to recognize.
