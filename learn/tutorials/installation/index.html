Install Cloth NeXt and Connect PPF

Cloth NeXt is the Blender integration layer. The PPF Contact Solver is separate software maintained by ST Tech / ZOZO. Cloth NeXt can work with a managed installation, a solver you installed yourself, or an already-running external server.

ManagedCloth NeXt downloads an explicitly approved compatible release from the official source, verifies it and installs it side by side.
External installationSelect a solver you already own. Cloth NeXt validates it but does not modify or update its files.
External serverConnect to a server that is already running. Cloth NeXt does not take over its process lifecycle.
Run Solver Health Check before the first production Bake.
