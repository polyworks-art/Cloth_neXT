Your First Simulation

Use one subdivided plane as Cloth and one simple mesh as Collider. Enable Cloth NeXt on both objects, assign the roles, choose a valid cache directory and keep the first Bake short. A 20 to 50 frame test is enough to verify the complete pipeline before you add animation or extra contact.

  1. Apply sensible object scale and start from clean geometry.
  2. Choose Cloth for the deforming object and Collider for the obstacle.
  3. Set the cache directory with Set Dir.
  4. Choose a material preset close to your target fabric.
  5. Bake a short range and inspect contact, stretch and settling.
If the tiny test fails, fix the setup first. Do not compensate for a broken pipeline by changing random material values.
