Bake and Live View

BAKE first validates the scene, prepares evaluated inputs and starts the external solver. Live View is progress feedback while the result is still being written. Cloth NeXt only exposes confirmed complete PC2 frames and holds the last confirmed frame until the next one is fully available. Finalized playback uses the normal final cache behavior.

Cancel uses the existing solver cancellation path. A cancelled or failed Bake should not destroy the previous valid playback result.
