Caches, Rebake and Recovery

Cloth NeXt treats playback caches as versioned production data. A successful Bake records the geometry and settings identity used to create the result. Changing solver-visible settings or geometry invalidates that relationship and a Rebake is required.

  1. The old valid result remains authoritative while a replacement Bake starts.
  2. The new cache is verified before Cloth NeXt hands playback over to it.
  3. Obsolete owned cache generations are cleaned only after the successor is committed.
  4. Recovery data is accepted only when it matches the expected solver and scene identity.
