# Cloth NeXt 2.2.28 Dev Changelog

Release date: 2026-08-12

Channel: Dev

Source commit: recorded by the Dev publication workflow

## Added

- Live Bake viewport auto-framing for all deformables.
- Smooth and Cinematic following modes with configurable response and margin.
- Expansion-safe framing that pulls back immediately while damping closer
  camera movement.

## Fixed

- Cancellation remains latched across the EXPORTING ownership transition.
- Cancelled terminal state and Recovery checkpoint status are no longer erased
  by a delayed background reset.
- New Bake and Resume attempts replace the previous terminal state through the
  normal controller transition.

## Validation

- Python integration, Recovery, cancellation, viewport-framing, extension
  source, packaging-policy, and artifact checks were run for this release.
- The external solver is not bundled in the extension package.
