# Cloth NeXt 2.2.0 Beta Changelog

Release date: 2026-07-30  
Channel: Beta  
Source tag: `2.2.0`

## Added

- Verified Protocol 0.13 / Schema 2 solver support alongside Protocol 0.11,
  including side-by-side managed and external installations.
- Animation-aware Character Collision Cage proxies.
- Hard and Soft Pin constraints with animated targets synchronized to Collider
  sampling.
- 75 categorized material presets.
- Estimated current solver-frame fill in the Bake Companion.

## Changed

- Animated Collider samples now improve motion fidelity without becoming
  additional logical solver frames or stretching simulation duration.
- Animated Collider and Pin preparation reuses evaluated data and exact cache
  identities to reduce repeated Blender work.
- Physics Properties now use clearer role-specific Setup, Simulation, Material,
  Shape, Collision, and Advanced workflows.

## Fixed

- Recovery checkpoints remain available after unexpected solver exits when the
  authenticated recovery state is still valid.
- Recovery, cache, and solver identities include the exact active solver release.
- Solver lifecycle, worker shutdown, stale Collider payloads, cancellation, and
  Blender reload paths received additional hardening.

## Distribution

- The verified `2.2.0` package is published to the Beta and Dev Blender extension
  repositories through GitHub Pages.
- The external PPF Contact Solver remains separate and is never included in the
  Cloth NeXt archive.
