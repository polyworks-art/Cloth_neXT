# Cloth NeXt 2.2.27 Dev Changelog

Release date: 2026-08-12

Channel: Dev

Source commit: recorded by the Dev publication workflow

## Added

- Verified Lumen support for PPF protocol 0.18 and schema 2 alongside Velune
  protocol 0.13 and schema 2.
- Exact official release metadata and secure explicit downloads for both
  supported solver releases.

## Changed

- Preferences expose only Velune and Lumen. Retired protocol 0.11 entries are
  hidden even when an old installation remains on disk.
- Protocol-specific parameter encoding omits CCD fields removed by Lumen.
- Recovery probes server compatibility independently before reconciling the
  interrupted project.

## Fixed

- Lumen Recovery Resume continues from the latest verified checkpoint without
  uploading or rebuilding the scene.
- Solver crash categories and multiline errors remain intact through status,
  health, session, and UI diagnostics.

## Validation

- Full Python test suite, extension source validation, release artifact scans,
  real Lumen integration scenarios, and Blender 5.2 Recovery Resume were run.
- The external solver is not bundled in the extension package.
