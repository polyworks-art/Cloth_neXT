REFERENCE

Documentation

A compact reference for the controls you can actually change in Cloth NeXt. The page follows the Blender UI: choose a role, configure only the panels relevant to that role, validate, then Bake.

Install the solver, assign Cloth and Collider roles, choose a material, validate and Bake.

Scope

This reference documents user-editable controls from the current Cloth NeXt source. Internal cache fingerprints, status fields and implementation-only state are intentionally omitted.

GETTING STARTED

First Bake

The shortest supported path from an ordinary Blender scene to a cached Cloth NeXt result.

StepAction
01 · SolverOpen Cloth NeXt Preferences, install or select a compatible solver, then run the health check.
02 · ClothAdd Cloth NeXt physics to the deformable and choose Cloth.
03 · ColliderAdd Cloth NeXt physics to collision geometry and choose Collider.
04 · MaterialPick a preset, then adjust only the material controls the shot needs.
05 · ValidateResolve Scene Health issues before starting the expensive part.
06 · BakeSet the Bake range, start the Bake and review the versioned playback cache.

Scene Roles

A role decides which controls appear and how the object participates in the shared solve.

RoleUse
ClothSurface deformable for garments and other sheet-like materials.
Cable / RopeCurve-based one-dimensional deformable.
Soft BodyClosed volumetric deformable using internal tetrahedralization.
Rigid BodyClosed solid object that moves as a rigid participant.
ColliderStatic or animated collision obstacle.
ForceEmpty-based scene force controls for gravity, wind and air response.

Practical: Pick the physical role that matches the object. Changing roles changes which panels are relevant; it does not duplicate the object.

Rest Shape

REFERENCE

Troubleshooting

Start with the visible CNX error code and Scene Health. Fix the reported cause before changing low-level solver values.

Intersections or tunneling

Check collider motion/capture, surface offset, collision gap and scene scale before touching advanced CCD values.

Flutter or jitter

Verify material stiffness and contact first, then add small Shape or Fold Damping values.

Bake runs out of memory

Reduce unnecessary collider density/samples, use proxies where appropriate and keep Memory Safety enabled.

Result is stale

Rebake after solver-visible settings, geometry or solver backend changes. Cloth NeXt fingerprints cached results deliberately.

Error reference

For a stable CNX code and its recovery steps, use the Error Index.

REFERENCE

Current Limitations

The integration is intentionally explicit about what is supported.

  • Current production support targets Windows x64 with a compatible NVIDIA GPU.
  • The PPF Contact Solver is installed separately and is never bundled with Cloth NeXt.
  • Topology-changing animation across a Bake is rejected where constant topology is required.
  • Playback requires stable vertex count and vertex order.
  • Cable / Rope uses a uniform simulated collision radius.
  • Soft Body requires a suitable closed manifold surface.
  • Capacity depends on topology, contact count, animated samples, quality, VRAM, RAM and frame count.
