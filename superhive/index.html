IN BLENDER

Set up the simulation from Physics Properties.

Cloth NeXt keeps the scene setup in Blender and handles the file exchange with the external solver.

  • Assign Cloth, Collider, Force, Rod / Cable or Soft Body roles
  • Choose one of 37 presets or edit the material values directly
  • Add Follow Animation pins and static or animated colliders
  • Run Scene Health Check, choose the frame range and start the bake
BAKE COMPANION

Watch the bake while it runs.

The companion window shows frame progress, solver activity, elapsed time, ETA and system usage. A running job can be cancelled without replacing the previous valid cache with incomplete output.
