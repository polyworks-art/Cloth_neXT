IN BLENDER

Role-specific setup in Physics Properties.

Cloth NeXt keeps scene setup inside Blender and exposes only the controls that matter for the selected simulation role.

  • Assign Cloth, Cable / Rope, Soft Body, Rigid Body, Collider or Force roles
  • Choose one of 37 fabric presets or edit the physical values directly
  • Add Static or Follow Animation pins, Sewing and vertex-group Friction regions
  • Use static, animated or topology-preserving deforming Collider geometry
  • Validate the evaluated Bake-start scene, choose the frame range and start the shared solve
DEDICATED BAKE WINDOW

Watch, cancel and recover.

The Bake window follows preparation and simulation with frame progress, solver activity, elapsed time, ETA and system usage. Cancelling a running solve attempts to save a verified recovery checkpoint, making Resume available when the solver state can be preserved.
